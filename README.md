# Blend operator guides

Independent educational guides for the unofficial `xAlisher/logos-blockchain-ui` fork. No Logos logos or marks.

- `/`: guide index
- `/blend/`: narrated Blend explainer, chapters and transcript
- `/reachability/`: narrated port-forwarding guide, decision map and router checklist

GitHub Pages publishes this branch from `/`. The application branches are independent.

Videos are served as MP4 files rather than embedded base64 so playback can use HTTP range requests. Public Sans is distributed with its OFL licence in `assets/OFL.txt`.
